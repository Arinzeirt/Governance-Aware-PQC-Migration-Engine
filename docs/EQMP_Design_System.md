# EQMP Design System

Version: 2.0

---

# Design Philosophy

Enterprise.

Minimal.

Professional.

Consistent.

The interface should resemble an enterprise command centre rather than a cybersecurity tool.

---

# Design Principles

- One primary action per page.
- Consistent spacing.
- Minimal colours.
- Uniform cards.
- Executive-first.
- Information hierarchy.
- Large whitespace.
- No visual clutter.
