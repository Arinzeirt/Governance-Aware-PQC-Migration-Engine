# Cryptographic Discovery & Inventory Framework

## Overview

The Cryptographic Discovery & Inventory Framework (CDIF) provides a structured methodology for identifying, classifying and maintaining an enterprise-wide inventory of cryptographic assets. It establishes visibility into where cryptography is deployed, how it is used and which assets may be vulnerable to future quantum attacks.

Without an accurate inventory, organisations cannot effectively plan or govern a post-quantum migration programme.

---

## Purpose

Many organisations cannot answer fundamental questions such as:

- Where is cryptography used?
- Which algorithms protect critical systems?
- Which certificates, libraries and protocols are quantum vulnerable?
- Which applications depend on legacy cryptography?

The framework provides a repeatable process for discovering and documenting these assets, creating the foundation for enterprise migration planning.

---

## Discovery Domains

The framework identifies cryptographic assets across multiple enterprise layers, including:

- Applications and Software Services
- APIs and Integration Platforms
- Databases and Storage Systems
- Web Servers and Network Infrastructure
- Identity and Access Management
- Cloud Services
- PKI and Digital Certificates
- Source Code Repositories
- Third-Party Software Components

Each discovered asset is recorded within a central inventory.

---

## Inventory Classification

Every discovered asset is classified using key attributes, including:

- Asset Owner
- Business Criticality
- Cryptographic Algorithm
- Key Length
- Protocol Version
- Deployment Location
- Data Sensitivity
- Quantum Risk Rating
- Migration Priority
- Compliance Requirements

This information supports governance, reporting and migration planning.

---

## Discovery Lifecycle

The framework defines a continuous lifecycle consisting of:

1. Discover
2. Classify
3. Assess
4. Prioritise
5. Monitor
6. Update

Rather than treating discovery as a one-time activity, organisations maintain a living inventory that evolves alongside enterprise systems.

---

## Enterprise Benefits

Implementing the framework enables organisations to:

- Establish complete cryptographic visibility.
- Reduce unknown security risks.
- Identify quantum-vulnerable technologies.
- Support governance and audit activities.
- Improve migration planning.
- Strengthen enterprise cyber resilience.
