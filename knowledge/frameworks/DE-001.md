# Migration Decision Engine

## Overview

The Migration Decision Engine (MDE) is a governance-aware decision-support framework that enables organisations to prioritise post-quantum cryptographic migration activities based on enterprise risk, business impact, technical complexity and organisational readiness.

Rather than attempting to migrate every cryptographic asset simultaneously, the framework provides a structured approach for identifying where migration should begin and how transformation should progress over time.

---

## Purpose

Enterprise environments contain hundreds or thousands of cryptographic assets with varying levels of business criticality. The Migration Decision Engine provides a repeatable methodology for evaluating these assets and determining the most effective migration sequence.

The framework transforms technical findings into executive-level decisions that balance security, operational continuity and strategic objectives.

---

## Decision Factors

The framework evaluates migration priorities using several core dimensions:

- Business Criticality
- Quantum Risk Exposure
- Data Sensitivity
- Regulatory Obligations
- Operational Dependency
- Technical Complexity
- Migration Readiness
- Resource Availability

Each factor contributes to an overall migration priority score.

---

## Decision Categories

Assets are grouped into four migration categories.

### Immediate Migration

High-value assets with significant quantum exposure and strong organisational readiness.

### Planned Migration

Important systems that require additional preparation before migration.

### Monitor

Assets with lower immediate risk that should continue to be assessed as technology and standards evolve.

### Deferred

Systems with limited exposure or dependencies that prevent immediate migration.

## Enterprise Benefits

The Migration Decision Engine enables organisations to:

- Prioritise limited resources effectively.
- Reduce operational disruption.
- Support executive decision-making.
- Improve governance transparency.
- Align migration with enterprise objectives.
- Build measurable migration roadmaps.
